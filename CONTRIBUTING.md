## How to Contribute
To begin contributing, clone the repository and create your own branch to start adding your own glam to the project. When you are done and are ready to add your addition (or subtraction) from the repo, simply:
```
git push origin [YOUR_BRANCH_NAME]
```
Once this is done, a Pull Request can be opened and your contribution will be reviewed before it is added to the main branch.

## Code Formatting Guidelines
To keep consistent code formatting, always ensure proper code indenting to prevent readability issues. For example:
```
def main():
print("Hello!")
```
Is not valid formatting and should be changed to:
```
def main():
  print("Hello!")
```
Also, to ensure total understandability with the code, ensure variable names are descriptive but not overly as to make the name redundant.

## Testing Requirements
Testing can be performed on the contributors' end by running their changes through the
```
unittest
```
Python module. Ensure all test cases pass before pushing any changes to the repository!

## Documentation Standards
Documentation for changes is loosely up to the contributor. For large contributions, a documentation folder can be created and subsequent files can be uploaded whenever these contributions are made. For smaller contributions, explicit documentation is not required outside of proper comments on changes made, which will be stored in GitHub.

## How to Report Bugs
If you notice a bug and want to report it, create an issue with the 'Issues' tab and describe the bug to allow for others to work with that bug. For large bugs that are negatively affecting the architecture of the codebase, report the issue to the repository owner(s) and also create an issue in GitHub.

## How to Propose New Features
To propose new features, create an issue for feature requests in the 'Issues' tab on GitHub, and describe what the feature is and how it will contribute to the project. Features can be implemented freely by the contributors as long as the features benefit the software as a whole.

## Community Guidelines and Expectations
All community members interacting with the project and repository must adhere to the Code of Conduct policy listed [here](CODE_OF_CONDUCT.md). Any violations of this Code will be strictly enforced by the repository owner(s) and may result in a permanent ban from the project depending on the severity of the violation.

# TicTacToes
This is a classic Tic Tac Toe game that puts the player against a bot that uses the Minimax artificial intelligence algorithm to create a foe that can be tricky to beat.

## What does the project do?
The project uses the minimax algorithm to create a system that will choose the most optimal path during the course of the game. By using recursion principles, each move from the player will allow the algorithm to find the most optimal move, take that move, and wait for the next move from the player. The game logic and algorithm will be primarily coded using Python, with the front-end being handled by HTML, CSS, JavaScript, and Python frameworks to connect the display with the back-end.

## Why is this project useful?
This project allows for the understanding of the a common artificial intelligence algorithm for developing two-person games. Also, the project will allow for individuals to become familiar with connecting a language like Python to front-end displays.

### Installation Instructions
To get started, ensure that you have the current versions of these languages and softwares:
  - Python 3.12+
  - Git 2.4+

#### Cloning into the repository
To clone into the repo, ensure Git is installed, and type in the command prompt:
```
git clone https://github.com/NAU-OSS/TicTacToe.git
```
Now you have all of the current files in the repository!

#### Switching to a new branch
Once the repo is cloned and you're ready to begin working with the project, create a new branch and switch to it using:
```
git switch -c [YOUR_BRANCH_NAME]
```
